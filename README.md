# Anagrafe → Onda

Pagina web che copia i dati delle colonne "gialle" del file ANAGRAFE (BDN) nelle colonne corrispondenti del file ONDA, con i capi nell'ordine dell'anagrafe, e fa scaricare il file onda compilato.

Apri: https://vittobodra-ui.github.io/importa-onde/

- Foglio BOVINI → colonne con lo stesso nome nel file onda (ESTREMI MODELLO INGRESSO → NUMERO MODELLO INGRESSO).
- Foglio DATI DELL'ATTIVITA: AZIENDA CODICE, CODICE FISCALE, CODICE SPECIE ripetuti su ogni riga.
- Le colonne U-Z del file onda (CODICE FIERA DESTINAZIONE … CODICE ASSEGNATO IN PRECEDENZA) vengono eliminate.
- Tutto gira nel browser: nessun dato esce dal computer.
