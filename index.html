Anagrafe → Onda

Carica il file ANAGRAFE e il file ONDA: i dati delle colonne gialle dell'anagrafe vengono copiati nelle colonne corrispondenti del file onda, con i capi nello stesso ordine dell'anagrafe. Poi scarichi il file onda compilato. Tutto avviene nel tuo browser, i file non vengono inviati da nessuna parte.

Colonne copiate dal foglio BOVINI: CODICE CAPO, CODICE_ELETTRONICO, RAZZA CODICE, SESSO, CODICE MADRE, da MOTIVO INGRESSO a CODICE AZIENDA DESTINAZIONE, NUMERO e DATA MODELLO USCITA, INTERVALLO DATE, DATA ESTRAZIONE DATI. Dal foglio DATI DELL'ATTIVITA: AZIENDA CODICE, CODICE FISCALE, CODICE SPECIE. Nella colonna A viene scritto sempre CAR-IT. Le altre colonne del file onda restano vuote.
