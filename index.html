Anagrafe → Onda

Carica il file ANAGRAFE e il file ONDA: i dati delle colonne gialle dell'anagrafe vengono copiati nelle colonne corrispondenti del file onda, con i capi nello stesso ordine dell'anagrafe. Poi scarichi il file onda compilato. Tutto avviene nel tuo browser, i file non vengono inviati da nessuna parte.

Colonne copiate dal foglio BOVINI: CODICE CAPO, CODICE_ELETTRONICO, RAZZA CODICE, SESSO, CODICE MADRE, da MOTIVO INGRESSO a CODICE AZIENDA DESTINAZIONE, NUMERO e DATA MODELLO USCITA, INTERVALLO DATE, DATA ESTRAZIONE DATI. Dal foglio DATI DELL'ATTIVITA: AZIENDA CODICE, CODICE FISCALE, CODICE SPECIE. Nella colonna A viene scritto sempre CAR-IT. Le colonne da CODICE FIERA DESTINAZIONE a CODICE ASSEGNATO IN PRECEDENZA (U-Z) vengono eliminate.

Carica due file con l'elenco dei capi (per esempio VET INFO e ONDA): ti dico quali capi ci sono in un file ma non nell'altro, in che riga si trovano, e quali dati sono diversi per i capi presenti in entrambi. I file non vengono inviati da nessuna parte.

Il capo viene riconosciuto dalla colonna CODICE CAPO o Identificativo. Dati confrontati: data ingresso/arrivo, data nascita, razza, sesso, azienda di provenienza, data uscita, azienda di destinazione (solo quelli presenti in tutti e due i file). Il numero di riga è quello che vedi in Excel.
